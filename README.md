# .github

Organization-wide GitHub files for [Street Side Software](https://github.com/streetsidesoftware).

GitHub reads this repository for files that apply to the whole organization.

| File                  | What it does                                                                                               |
| --------------------- | ---------------------------------------------------------------------------------------------------------- |
| `profile/README.md`   | The introduction on the [organization page](https://github.com/streetsidesoftware).                        |
| `.github/FUNDING.yml` | The default Sponsor button, for every repository in the organization that has no `FUNDING.yml` of its own. |

A repository's own copy of a file always replaces the default here.

The `static/` folder holds Markdown blocks that the organization's READMEs inject with
[inject-markdown](https://github.com/streetsidesoftware/inject-markdown):

| File                    | What it is                                           |
| ----------------------- | ---------------------------------------------------- |
| `static/sponsor.md`     | The sponsor buttons, with dark-mode images.          |
| `static/sponsor-pub.md` | The same buttons as plain Markdown images.           |
| `static/footer.md`      | The "Brought to you by Street Side Software" footer. |
