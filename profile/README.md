# Street Side Software

We build [CSpell](https://cspell.org), a spell checker for code, and the tools around it.

## Projects

| Project                                                                                              | What it is                                                          |
| ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| [CSpell](https://github.com/streetsidesoftware/cspell)                                               | The spell checker: a command-line tool and a library.               |
| [Code Spell Checker](https://github.com/streetsidesoftware/vscode-spell-checker)                     | CSpell as a VS Code extension.                                      |
| [cspell-dicts](https://github.com/streetsidesoftware/cspell-dicts)                                   | Dictionaries for natural languages, programming languages and more. |
| [vscode-cspell-dict-extensions](https://github.com/streetsidesoftware/vscode-cspell-dict-extensions) | Language dictionaries as VS Code extensions.                        |
| [cspell-action](https://github.com/streetsidesoftware/cspell-action)                                 | Check spelling in a GitHub workflow.                                |
| [cspell-cli](https://github.com/streetsidesoftware/cspell-cli)                                       | CSpell as a pre-commit hook.                                        |
